Cell 5 · code

# convolve for each variation of window size and SD
window_sizes = [5,15,25,50,100,2000]
sigmas = [0.5,2,5,10,25,500]
convolved_outputs = {}
for window,sigma in zip(window_sizes,sigmas):
    gaussian_window = signal.windows.gaussian(window,sigma)
    gaussian_window = gaussian_window / np.sum(gaussian_window)
    convolved_outputs[f'window{window}'] = signal.convolve(noisy_signal,gaussian_window)

Cell 6 · code

# plotting everything in sub plots including the noisy signal
fig, axs = plt.subplots(3, 2, figsize=(15, 10))

    axs[i].plot(convolved_output)

plt.tight_layout()

## Part A Explanation

As is observed in the above plot, as we increase the window size and the standard deviation, the amount of smoothing is greatly increased

and therefore there is less noise observed in the signal.

But this comes with a trade-off of losing information the more we smooth the signal.

As it is with all other trade offs, the best option is to balance the wins and losses therefore,

* i am choosing window size 50 and sigma 10 *

as my best estimator of the signal provided. This balance point seems to keep the most amount of information by avoiding truncation in the edges

and also estimating the signal as best as it could.

But to prove that, we need further analysis, which will be done in the following parts.

# Estimating the noise by subtraction
smoothed_signal = convolved_outputs['window50']
# equate size of smoothed signal to the original signal by slicing from front and back
# since the original signal had 5000, the smoothed signal will have N+M-1
# where N is the original signal size and M is the window size,
# so we need to slice 25 from the front and 24 from the back
smoothed_signal = smoothed_signal[25:-24]
estimated_noise = noisy_signal - smoothed_signal
# plotting the original signal, smoothed signal and estimated noise
plt.figure(figsize=(15, 5))
plt.plot(noisy_signal, label='Noisy Signal')
plt.plot(smoothed_signal, label='Smoothed Signal (Window Size: 50, Sigma: 10)')
plt.plot(estimated_noise, label='Estimated Noise')
plt.xlabel('Time')
plt.ylabel('Amplitude')
plt.legend(
    fontsize=9,
    loc='upper right',
    ncol=3,
    bbox_to_anchor=(1,1.02)
)
plt.title('Original Noisy Signal, Smoothed Signal and Estimated Noise')
plt.show()

Cell 10 · markdown

## Explanation Part B

Although I could not find credible sources on how to make the size of the convoluted signal and the original signal sizes the same,

I decided since we padded on both sides, I sliced the convoluted signal on both sides to equate it to the original signal.

By subtracting the smoothed signal from the Noisy signal, we are making the assumption that the noise is an additive noise and

not a multiplicative noise, which would have made things much more difficult.

As we can see in the above plot, the estimated noise(green color line) is almost opposite of the smoothed signal(orange color line).

And by adding these opposit signals, you would intuitively get a much more toned down(low aplitude) signal, which is ovserved in the

blue color line.

# To calculate the SNR, we can use the formula shown in the hand written pdf in great detail
# SNR = 10 log (signal power/ Noise power)

smoothed_signal_power = np.mean(np.abs(smoothed_signal)**2)

noise_power = np.mean(np.abs(estimated_noise)**2)

SNR = 10 * np.log10(smoothed_signal_power/noise_power)

print(f"Signal to Noise Ratio => {np.round(SNR,2)} Decibels")

Signal to Noise Ratio => 9.4 Decibels

Cell 13 · markdown

## Explanation Part C

Following the formula driven in the hand written pdf, we get an SNR of 0.36 decibels which is quite low

Signal quality is directly and positively proportional to the SNR value, and in here we have too much noise in the original signal.

For context, a good SNR value would be in the range of 20 dB or more but we only have 0.36!!
