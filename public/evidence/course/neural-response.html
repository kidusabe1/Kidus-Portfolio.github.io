# My reasoning towards the question

Cell 9 · markdown

What i am going to do is for every stimulus, I am going to create a dict to slice the spike_times array some x amount of time before and y amount of time after the stimulus time.

and then I will count each stimulus(key of the dictionary) as if they are separate trials.

From simple observation, it is easy to know that the **stimulus happens every x.501 second for about 100 times**

For pre stimulus, I am going to use **200ms** and for post stimulus I am going to use **800** ms initially, based on the

guess that most of the interesting activity happens in this time window.

Cell 10 · code

trial_dict = {}

for i in stimtimes:
    trial_dict[i] = []
    for j in spiketimes:
        if j >= i-200 and j <= i+800:
            trial_dict[i].append(j-i) # this line here is where the aligning happens, we are storing the time relative to the stimulus onset

pre_stimulus_mean_firing_rate = {}

post_stimulus_mean_firing_rate = {}

for key, value in trial_dict.items():
    trial_dict[key] = np.array(value)

    pre_stimulus_mean_firing_rate[key] = len(trial_dict[key][trial_dict[key] < 0]) / 0.2
    post_stimulus_mean_firing_rate[key] = len(trial_dict[key][trial_dict[key] >= 0]) / 0.8


mean_firing_rate_pre = np.mean(list(pre_stimulus_mean_firing_rate.values()))
mean_firing_rate_post = np.mean(list(post_stimulus_mean_firing_rate.values()))

## Explanation Part A and B

Just by computing the pre and post stimulus mean firing rate across the 100 stimulus

the drastic change in the absolute mean firing rate is evident. But what is more interesting is

how the firing rate changes over time.

for that, we would have to do the peristimulus time histogram with binned spike count averages.

Cell 14 · markdown

# Part C

Cell 15 · markdown

To better understand how the stimulation changes the mean firing rate, I will proceed with binning and calculating the

average spike count normalized to rate for each bin and draw a peristimulus time histogram.

for this, I am going to use a time bin of 25 ms.

Changing the bin size really did not give me much of an insight so I stuck with 25ms bins.

Cell 16 · code

# Define the time window for the PSTH

time_window = np.arange(-200, 800, 25)
psth_counts = np.zeros(len(time_window)-1)

for key, value in trial_dict.items():
    counts, _ = np.histogram(value, bins=time_window)
    psth_counts += counts

psth_firing_rate = psth_counts / (len(stimtimes) * 0.025)

Cell 17 · code

plt.figure(figsize=(10, 6))
plt.bar(time_window[:-1], psth_firing_rate, width=25,edgecolor='black',align='edge')
plt.xlabel('Time (ms) relative to stimulus onset')
plt.ylabel('Firing Rate (Hz)')
plt.title('Peri-Stimulus Time Histogram (PSTH)')

# Part D & Conclusion


From this histogram with bin size of 25ms, I can understand that the neuron has a baseline rate of 20(plus or minus 5) firing rate but

almost 5 ms after being stimulated, the firing rate is increased quite drastically, to over 100 spikes/second for a duration of about 75ms.

But what is interesting is that the neuron goes quiescent after this hightened activity. To be honest, I am not certain that this is due to the

stimulus but I am fairly sure that it is because it is consistent across trials(since this is the average of 100 trials.)
